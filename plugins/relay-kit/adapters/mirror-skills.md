# Adapter: mirror-skills

**Used by:** `/yourturn`
**Turn it on if:** you use a second agent tool alongside Claude Code that reads its instructions
from a different directory, and you keep one canonical copy in the repo.

## Why

One source of truth, mirrored outward. The moment the mirror is generated by hand, the two copies
drift, and the tool reading the stale mirror behaves in ways nobody can reproduce.

Regenerating right after a pull is the cheapest possible moment: the source is definitively fresh,
and no work has been done against the old copy yet.

## Configure

Set the source and the mirror in your relay config's **Notes** section, for example:

```
mirror-skills: plugins/relay-kit/skills/ -> .agents/skills/
```

## Run

```bash
test -x <sync-script> && bash <sync-script>
```

If your setup has no script, a plain mirroring copy works:

```bash
rsync -a --delete <source>/ <mirror>/
```

## Report

- Ran and succeeded → one line, "skills mirror synced".
- No script and no configured mirror → say nothing. Not everyone has a second tool.
- Failed → report the error, but do not block the pickup. A stale mirror is a nuisance; a blocked
  pickup is worse.

## Rules

- **The mirror is generated. Never edit it, never treat it as the source.** If the two ever
  disagree, the source wins and the mirror gets regenerated.
- Keep the mirror out of version control, so nobody can accidentally commit a change made there
  and turn a generated copy into a second source of truth.
